# Mods

Repositório para armazenar e versionar meus mods.

## Estrutura

```
mods/
├── _modelo/          # Modelo para criar um novo mod (copie esta pasta)
│   └── README.md
└── <nome-do-mod>/    # Um diretório por mod
    ├── README.md     # Descrição, versão, compatibilidade, instalação
    └── ...           # Arquivos do mod
```

## Como adicionar um novo mod

1. Copie a pasta `mods/_modelo` para `mods/<nome-do-mod>` (use letras minúsculas e hífens).
2. Coloque os arquivos do mod dentro da nova pasta.
3. Preencha o `README.md` do mod.
4. Adicione uma linha na tabela abaixo.
