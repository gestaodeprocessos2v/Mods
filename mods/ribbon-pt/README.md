# ribbon-pt

Tradução para o português do [ribbon](https://github.com/robonuggets/ribbon), de Jay E (RoboNuggets), sob licença MIT.

Mostra uma faixa acima do prompt com:

- **Uso** das janelas de 5 horas (5H) e 7 dias (7D): verde até 50%, laranja até 75%, vermelho acima; **ALTO** quando restam menos de 15%.
- **Quando cada janela renova.**
- **Cache do prompt:** QUENTE por até 1 hora depois da última requisição, depois FRIO, com o custo estimado da próxima mensagem. No app desktop, o botão Mostrar/Ocultar abre um cartão com os detalhes.

Não gasta tokens: só lê os números que o próprio Claude Code já tem.

## Instalação

```
/plugin install ribbon-pt --marketplace gestaodeprocessos2v/mods
```
